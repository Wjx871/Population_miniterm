## 复现

从仓库根目录运行，无需下载或运行模型。

```bash
ai-service/.venv/bin/python evaluation/compare_qingdao_retrieval.py \
  --output tmp/qingdao-local-repeat.json
```

获得明确授权且服务配置就绪后，从远程服务器以 `--remote` 重跑，向量融合与重排从完全相同的候选池计算名次。报告记录模型标识、各阶段时间、每题的排名和接口降级。请求失败的阶段记为未完整测量。当前缺少远程向量与重排 API，只有模拟接口验证，未取得该两阶段的实测效果。 [远程适配说明](../ai-service/README.md)
