## 实际目标环境执行顺序

1. 选择长期 Linux/Docker 目标或临时 CI；CI 完成销毁实验卷，不保留在线站点。
2. 备份实际数据库、文件及必要配置，在隔离环境验证恢复；既有库执行适用迁移至 V4_015，不重复导入快照。
3. 复制 config/docker/.env.example，填写连接、随机 JWT 和 broker 密码；OCR 密钥本地注入。
4. 先单实例，再合并主从、双实例、RabbitMQ 覆盖文件，按交接说明核对网络、卷和配置。
5. 执行 scripts/ops/verify-deployment.ps1，可通过 OPS_ADMIN_TOKEN 验证所有运维接口，不保存令牌。
6. 虚构材料验证真实业务、OCR、异常分支，再执行迁入办结及恢复演练，记录版本与证据。
