## 二、先明确现有基础

### 已有基础

- `PolicyAssistantService.java`：本地 Markdown 加载、分块、中文二元组 BM25 风格检索、引用与可选大模型回答。
- `PolicyTaskAgentService.java`：规则式意图识别、追问改写、证据处理和建议动作。
- `PolicyWorkflowService.java`：基于检索证据生成材料与流程清单。
- `src/main/resources/policy-knowledge/`：已有业务指南，可继续复用。
- `PaddleOcrHttpClient.java`：身份证 OCR HTTP 适配，尚不能据此宣称本地识别服务已可用。

### 需要特别注意

- 当前 Controller 的 `/api/assistant/policy/query` 返回任务助手的 `AgentResponse`，旧 RAG 设计文档描述的是较早的内部响应，接口要以当前 Controller、DTO 和实际响应为准。
- 内置知识多为 `PROJECT_GUIDE`，不是自动获得权威性的正式政策库；记录真实来源，不编造政策版本和生效日期。
- AI 源码在 `ai-service/`，但本机推理环境已清理。后续与部署负责人约定远程地址和服务部署，不恢复本地模型。
- 现有规则助手、OCR 接口适配都要保留为基线，不能更换后失去对照。
