## 心灵树洞主机

另一台 Ubuntu 主机为 4 核 16GB、180GB，已有重要项目。当前没有在该机执行命令或改动。按用户要求，优先通过独立宝塔机承载邑循，避免共用应用环境和主机资源。

独立目录、账户、容器网络、数据库与 CPU/内存限额能降低相互影响，但仍共享宿主资源，不能承诺“丝毫不干扰”。Docker 容器默认没有 CPU/内存资源限制，需要显式配置，见 [Docker 资源约束文档](https://docs.docker.com/engine/containers/resource_constraints/)。不把容器隔离等同于满足该主机零干扰要求。

## 后续顺序

1. 宝塔机重装与资源验收已完成，继续保持心灵树洞主机不动。
2. 轻量 Linux 服务环境，模型权重不落用户 Mac；服务不与其他项目共用数据库或配置。
3. 配置用户选定的远程 API，不自动购买服务或复用其他项目密钥。
4. 先完成单请求、引用、无依据拒答与故障降级验收，再增加远程向量化/重排和小流量检查。
5. 结合到期时间决定后续保留/续费，由用户决定，不自动续费或升级。

本评估不代表生成接口或远程 RAG 已上线。已有检索实验与清理记录见 [RAG 第二阶段记录](rag-v2-report.md)。
