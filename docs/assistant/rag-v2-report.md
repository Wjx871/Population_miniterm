# 邑循 RAG 第二阶段记录

日期：2026-11-01；负责人：王家兴。

> 本文保留本地模型方案终止时的阶段状态。后续远程 DeepSeek 与页面链路已另行完成，当前结果见 [V0.3 验收报告](deepseek-rag-validation-report.md)，不改写本轮历史数据。

## 当前结论

混合检索和重排序已完成开发诊断实验；本地模型方案因占用内存、影响电脑正常使用而终止。真实生成验收与页面联调没有完成，不能将本轮工作称为完整 RAG 已交付。用户已明确禁止在本机下载或运行模型，后续改用远程 API 或独立服务器。

## 保留的实现

- 复用项目知识库，增加来源类型、地区、生效/失效日期约束，先过滤适用来源再检索。
- 中文词法检索、向量检索、RRF 名次融合、跨编码器重排序与语料版本缓存；本机模型与缓存已移除，该模型实现仅保留源代码供远程环境参考。
- 完整原文证据选取、引用编号和逐字匹配校验、完整句边界校验；生成失败时明确降级。
- 只读 Java 适配与原响应兼容，保留业务权限，不执行审批/人口写入；开关当前为关闭。
- 固定挑战集、原始结果、不覆盖历史基线的评测脚本。
