## 回答质量控制

1. 在检索与外部调用前处理敏感请求、地区、时间和来源适用性；项目指南不能替代地方正式政策。
2. 保留原问，再生成最多两条同义检索问句；多路结果按名次融合，并保留各路优先候选。
3. 模型从最多 16 个候选片段中选择原文。服务校验 JSON、来源编号、逐字匹配和完整句边界，避免截掉否定或前置条件。
4. 回答只使用通过校验的选文，引用重新连续编号，清除 Java 旧规则可能产生的不一致清单。
5. 允许模型弃答；失败时明确标记降级。未配置 Key 时不请求模型，鉴权/余额/限流错误不自动重复收费请求。
6. 业务下一步入口继续受 Java 权限控制，模型不执行 SQL、不创建申请、不审批或修改人口主档。

为便于核验，当前采用原文摘录回答。它能限制编造，但选中原文并不自动保证回答充分，仍需评估相关性与条件覆盖。

## 密钥与资源边界

- DeepSeek Key 由用户隐藏输入，仅保存在服务器 root 可读的 `/etc/yixun-ai/provider.env`，不下载到本机。
- 专用 `yixun-tunnel` 账号仅允许转发服务器 `127.0.0.1:8091`，强制命令仅返回 RAG 内部调用密钥；普通命令和转发 22 端口均实测被拒。无 Shell/sudo/TTY 权限。
- SSH 严格核验从已认证腾讯云控制台取得的主机公钥。本地内部密钥配置权限为 600，私钥和相关文件位于 Git 忽略目录，前端不持有密钥。
- 8091 仅监听专用服务器的回环地址。
- 本机模型与推理环境已清理，不恢复模型权重或历史推理依赖；本机仅运行业务开发服务和 SSH 转发。

运行与更换密钥步骤见 [部署说明](deepseek-deployment.md)。服务所在试用实例于 **2026-11-11 17:14:16** 到期，保留、续费或迁移由用户决定。

3. **正式知识库**：维护可核验的官方来源、适用地区、版本和生效日期；未知信息保持未知，不编造。
4. **远程检索增强**：在明确服务商、费用和数据范围后，再评估远程 Embedding/重排，与本次固定结果做对照；本机不安装模型。
